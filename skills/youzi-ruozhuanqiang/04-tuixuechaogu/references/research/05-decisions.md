# Agent 5: 决策记录与行动

## 来源：本地素材（退学炒股经历.pdf + 退学炒股交割单分解修订本）

### 关键决策时间线

#### 决策1: 选择炒股而非读书（2015-10）
- **背景**：股灾后配资公司跑路，血本无归
- **选择**：离开学校、离开女友、离开常州，去广东职业炒股
- **初始资金**：1.67万
- **逻辑**：对股票的热爱 > 对学历的需求
- **后果**：开启了从1.67万到1000万的旅程
- **反思**：从未公开表达过后悔

#### 决策2: 第一次配资破产后再次配资（2016年初）
- **背景**：2015股灾爆仓破产
- **选择**：再次使用配资
- **后果**：又一次被击败，2016-05再次一无所有
- **反思**：
  > "之后对市场有了敬畏之心，姿态也放低了很多...然而在两个月前再生贪念，以为自己能够控制风险，又配资了。结果是我不能控制的，又一次把我彻底击败。"
- **教训**：配资 = 毒药，但贪念会让人忘记教训

#### 决策3: 声明退出机制（2016-01-17）
- **背景**：资金2.6万，处于低谷
- **决策**：给自己设定deadline——一年后资金不到30万就放弃
- **逻辑**：给自己压力和底线
- **结果**：最终突破了目标

#### 决策4: 改密码断网休息（2016-09-30）
- **背景**：连续割肉，还剩5万
- **决策**：主动休息，改交易软件密码，关看盘软件
- **逻辑**：意识到状态不好时不应继续操作
- **启示**：懂得「不做」比「做」更重要

#### 决策5: 启动"一年20倍"计划（2017-04-24）
- **背景**：资金4.9万，心态调整后
- **决策**：公开宣布挑战
- **结果**：2017-04-27到2017-08-29，4个月资金从4.9万到21.3万
- **关键交易**：北京科锐（超3个板）、津膜科技（+31%）

#### 决策6: 全仓万兴科技（2018-03-02）
- **背景**：资金80万
- **决策**：55块全仓买进万兴科技
- **结果**：2018-03-23资金177万（估计119出局）
- **逻辑**：次新股弱转强模式的经典应用

#### 决策7: 全仓必创科技（2018-03-28）
- **背景**：资金226万
- **决策**：47块全仓买进必创科技
- **结果**：2018-04-02资金302万
- **逻辑**：同上，次新股模式的连续应用

### 交割单中的典型交易决策

#### 高胜率交易模式

**模式A: 弱转强（最核心）**
- 北京科锐：无量一字板后放量跟进，+52%
- 津膜科技：无量一字板后放量跟进，+31%
- 万兴科技：次新股连续一字板后放量，弱转强
- 必创科技：同上模式
- **核心逻辑**：超预期 = 套利空间

**模式B: 新龙头卡位**
- 碳中和题材：中材节能见顶后，华银电力实现卡位
- **核心逻辑**：题材不死，换龙头继续

**模式C: 超预期加速**
- 主流题材日内龙头，次日分歧后高开快速缩量上板
- **核心逻辑**：分歧后的一致 = 加速

#### 失败交易分析

**失败1: 配资爆仓（2015年）**
- 原因：10倍杠杆，无法承受波动
- 教训：杠杆是双刃剑

**失败2: 违背模式原则**
- 某些交易"买入位置有些勉强"
- "好像违背了自己的操作原则"
- 教训：纪律 > 判断

**失败3: 选股失误**
- "和深大通二选一，选了弘高创意这个垃圾"
- 教训：二选一往往选错，需要更强的筛选标准

**失败4: 止损不坚决**
- 同力水泥、大同煤业两次失败
- 教训：该模式在次新股上成功率较高

### 决策特征总结

| 维度 | 特征 |
|------|------|
| 仓位管理 | 倾向全仓或重仓单只股票 |
| 持股周期 | 超短线（T+1到T+3为主） |
| 买入时机 | 竞价/开盘阶段为主 |
| 卖出时机 | 次日开盘或分时高点 |
| 止损方式 | 集合竞价割、破均线卖、破前日收盘价割 |
| 加仓方式 | 很少分批，倾向于一次性买入 |
| 选股偏好 | 次新股 > 老股；题材龙头 > 跟风 |

### 行为模式中的矛盾

1. **知道配资危险 vs 反复使用**：两次因配资破产，但还是忍不住
2. **知道心态重要 vs 情绪化操作**：反复反思心态，但还是被情绪左右
3. **知道纪律重要 vs 偶尔违背**：交割单中有"违背原则"的交易
4. **极度自信 vs 极度自卑**：在同一天内可能从天堂到地狱
