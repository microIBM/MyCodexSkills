## 核心发现

### 人物画像
- 87年生，2010年参加职业炒手杯时还是大学生（一门计算机公选课没过差点延期毕业）
- 主席位：银河证券绍兴路
- 从大学小散到著名游资，8年1万倍的传奇
- 比赛期间市值：2010年3月初始 → 2010年11月869万 → 后续过亿

### 交易风格提炼
- **核心策略**：龙头打板。只做涨停板，只做强势板块龙头
- **持股周期**：超短线，通常1-3天
- **成功率**：70%以上（第二天高抛的概率）
- **关键特征**：执行力极强，像军人一样一板一眼

### 五大核心理念
1. 涨停是强势的最高表达，只做涨停板
2. 强势板块里的强势股（龙头优先）
3. 大题材从头吃到尾（做T贯穿全程）
4. 执行力是生命线（铁一样的纪律）
5. 空仓是最高境界（没板可做就等）

### 关键战法
1. **突破板三日战法**：第一天突破板必打，第二天做T，第三天全部高抛
2. **连板开板战法**：连板票开板必打，胜率超50%
3. **大题材龙头战法**：从启动做到高潮，中间做T降成本
4. **三连板惯性法则**：有三必有五，第四天加仓第五天清仓
5. **板块点火布局**：通过布局同板块其他个股为龙头铺路

### 核心教训
1. 分心炒股是最大敌人（每次分心都大亏）
2. 手痒追涨必须克制（没好板就空仓）
3. 节奏错了要停手调整
4. 资金大了必须调整模式（分仓）
5. 不做不熟悉的领域（新股、期指等）

## 与其他游资的异同

| 维度 | 赵老哥 | 退学炒股 |
|------|--------|----------|
| 核心策略 | 龙头打板 | 弱转强+超预期 |
| 持股周期 | 1-3天 | 1-2天 |
| 买点 | 涨停板排队 | 弱转强转折点 |
| 卖点 | 鼎盛期清仓 | 强转弱即卖 |
| 仓位 | 初期满仓→后期分仓 | 灵活仓位 |
| 情绪管理 | 自嘲+反省 | 理性+克制 |
| 核心优势 | 执行力+题材敏感度 | 超预期判断力 |
