# 作手江南 · 调研摘要

## 人物概况

**名称**：作手江南（Zuoshou Jiangnan）
**类型**：游资圈教学型选手
**核心方法**：短线滚动操作——在一只牛股上反复操作，将利润最大化
**活跃时间**：2019年（课程发布时间）
**来源**：公众号"定量交易"，第15课教学课程

## 核心素材

### 1. 课程内容："一个牛股的交割单"（第15课）

课程以美锦能源（000723）为案例，展示了一线游资如何在一只牛股上反复滚动操作，从5元附近做到20元以上，一个月翻四倍。

**课程要点**：
- 教学目的：解决"买了牛股但卖飞"的问题
- 核心方法：滚动操作，在一只股票上反复买卖
- 操作风格：打板与低吸结合
- 附加案例：安控科技（芯片概念）、金科文化（网络游戏）

#### 操作特征

1. **分批操作**：同一天内多次买入或卖出，每次10-20万股
2. **滚动操作**：卖出后又买回，在同一股票上反复操作
3. **价格区间宽**：从5元做到20元，跨越多个整数关口
4. **交易频率高**：平均每天2-5笔交易
5. **打板与低吸结合**：既有涨停板买入，也有回调低吸

### 3. 安控科技（300370）案例

**板块**：芯片概念
**操作逻辑**：
- 之前跟着板块走强后，K线图上留下很长的阴线（压力位）
- 12月11日尾盘突然异动，一度大涨拉升（试盘动作）
- 随后几天一路震荡上行
- 今日开盘后直接路上行，在箭头标注点介入，随后直接涨停

**关键信号**：
- 长上影线（试盘）
- 板块走强（芯片概念）
- 突破确认后介入

### 4. 金科文化案例

**板块**：网络游戏
**操作逻辑**：
- 昨天明显有试盘动作，最后收个上影线
- 网络游戏板块明显走强
- 今天直接平开后，直线拉升上板

**关键信号**：
- 上影线（试盘）
- 板块效应（网络游戏走强）
- 平开是最佳介入点

## 交易思维框架提炼

### 核心理念

1. **滚仓最大化**：在一只牛股上反复操作，而不是频繁换股
2. **大赚小亏**：低吸失败保本出来，成功了让利润奔跑
3. **上影线战法**：试盘观察，确认突破后介入
4. **板块效应**：个股运作离不开板块支撑
5. **信心持有**：对选中的股票要有信心，不轻易卖出

### 交易系统

**选股**：热点板块 + 试盘动作 + 技术形态
**买点**：低吸为主（试盘后低开/平开）、突破确认后加仓、打板为辅
**卖点**：冲高减仓、趋势转弱止损、大面积出货
**仓位**：分批建仓、滚动操作、集中持仓

### 心智模型

1. 滚仓思维：在一只股票上反复操作
2. 盈亏比思维：小亏大赚
3. 试盘思维：观察主力意图
4. 板块思维：先选板块再选个股
5. 信心思维：对股票有信心才能持有

### 决策启发式

1. 有试盘动作才关注
2. 板块走强才介入
3. 低开平开是买点
4. 突破确认后加仓
5. 冲高就减仓
6. 失败了保本出来
7. 有信心就持有
8. 多用心思去学习

### 表达DNA

- 语气：温和教学型，"废话不多说，直接上干货"
- 词汇：卖飞、滚动操作、试盘、板块效应、大赚小亏
- 风格：先案例后总结，分享交割单 → 分析逻辑 → 提炼方法
- 口癖："好好学习吧，祝大家天天都抓涨停板"

## 与其他游资的对比

| 维度 | 作手江南 | 退学炒股 |
|------|----------|----------|
| 核心方法 | 滚动操作（一只股票反复做） | 弱转强（找到转折点） |
| 持仓风格 | 同一股票长期操作 | 快进快出，2-3天 |
| 买点 | 低吸+打板 | 弱转强确认点 |
| 卖点 | 冲高减仓 | 强转弱即卖 |
| 适用场景 | 趋势明确的牛股 | 次新股、题材股 |
| 风险特征 | 判断错误会越套越深 | 止损快，亏损有限 |

## 调研局限

1. 课程内容较短（13页），信息量有限
2. 只有一个完整案例（美锦能源），缺乏更多验证
3. 安控科技和金科文化案例描述较简略
4. 缺乏交易者的个人背景和历史记录
5. 课程可能有教学美化，实际操作可能更复杂
6. OCR提取可能有误差，部分数字和文字可能不准确
