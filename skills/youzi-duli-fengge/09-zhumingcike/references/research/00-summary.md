# 著名刺客·蒸馏摘要

## 数据源
1. `著名刺客手记_2013-2016.txt` — 淘股吧论坛手记，包含交易哲学、龙虎榜分析、复盘笔记（2013-2016）
2. `著名刺客50万到104万实盘持仓汇总.txt` — 2016年3月-9月实盘记录，50万做到104万
3. `著名刺客500万到800万实盘交割单.txt` — 2016年10月-12月交割单，500万做到800万

## 关键发现

### 交易风格定位
- **超短选手**：隔日超短为主，持股最长不超过3天
- **满仓一股**：小资金快速做大的核心策略
- **扫板高手**：涨停板确认的瞬间买入，这是他的标签
- **全能型**：打板为主，低吸和追涨为辅，但有严格条件限制

### 核心哲学（一句话）
**紧随主流，万法归一**——所有操作方法的根本就是紧随市场主流板块和龙头个股。

### 选股逻辑
- 只做龙头，远离"屌丝股"
- 题材核心是"打动人心"——让人觉得小公司能变大公司
- 行业趋势性大题材 > 国家政策短线热点
- 群众基础好、股性活跃的"大众情人"优先
- 曾经牛过的股票市场有记忆，再牛概率大

### 买点
- 主力手法：扫板（涨停确认瞬间买入）
- 辅助：低吸（市场恐慌时）、追涨（市场转好时）
- 核心：预判+跟随+应变

### 卖点
- 自认是最弱环节，"一直在路上"
- 板块走弱就出，跟风股冲高就走
- 龙头可以多拿

### 仓位管理演变
- 50万阶段：满仓一股，天天换股
- 500万阶段：依然激进，满仓追高
- 每次回撤 = 分仓多股 + 偏离主流
- 每次大赚 = 满仓一股 + 交割清爽

### 资金曲线特征
- 50万→104万：约6个月，收益100%+
- 500万→800万：约2个月，收益60%+
- 最大回撤来源：气氛好时放松标准、买到弱股死扛

### 常见错误模式
1. 偏离主流 → 回撤
2. 气氛好时放松标准 → 买到弱股
3. 分仓多股 → 利润被稀释
4. 卖股太早 → 卖飞牛股
5. 情怀交易 → 亏损（"在A股甭谈情怀"）

### 独特见解
1. **复利公式论**：交易和物理学一样，最有用的公式都是最简洁的——紧随主流
2. **市场记忆论**：市场由交易者组成，因此有记忆，牛股还会再牛
3. **分歧利润论**：有分歧才有关注，有关注才有波动，有波动才有利润
4. **时间敌人论**：选错股不会妨碍做大，但时间会
5. **零和市场论**：市值配售不会带来新资金，冻结资金配售才能带来牛市
