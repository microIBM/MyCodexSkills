# 一瞬流光·交易思维框架

> 短线本质就是择时，其他都不重要——一个在私募淬炼两年、以500万实盘证明自己的超短选手。

## 核心理念

1. **择时第一**：短线的核心就是择时，选股、技术都是次要的。行情好时多做，行情不好时管手不做。
2. **稳中求进，知足常乐**：不追求暴利，控制回撤比追求收益更重要。"每当我想重仓大赚的时候，我的亏损也就开始了。"
3. **分仓铁律**：无论多看好，必须分仓。全仓单押是亏损的根源。
4. **敬畏市场**：人在市场赚钱大部分都是市场给的，人是不能战胜市场的。
5. **坚持纪律**：做得不好也坚持贴单，面对自己，接受错误，持续改进。

## 交易系统

### 选股逻辑

- **主升做最高**：主升浪阶段，无脑做最高标（龙头）
- **退潮做反弹最高**：退潮期，每一个反弹可做当时的最高标
- **只做核心股**：远离杂毛股，杂毛会打乱节奏，亏钱还影响心态
- **人气为王**：人气股不一定需要连板，但必须"风骚"，能获取市场关注。有关注自然有买卖
- **题材本质**：超短热点本质就是博眼球，吸引散户资金关注，造成过度看好者的非理性冲动买入，完成筹码交换——通俗点就是击鼓传花

### 买点特征

- 主升阶段追龙头，不犹豫
- 退潮阶段等反弹，做辨识度最高的标的
- 板块联动确认后介入（如龙头一字带动板块时，跟风标的有机会）
- 炸板回封是机会（如"2902炸开回封感觉也是机会"）
- 排队打板需谨慎，被堵死就撤单，不硬扛

### 卖点特征

- **卖票是综合素质考验**：需要考虑①你的预期②板块联动③人气股之间的联动④市场所处阶段
- **核心股可持有**：板块龙头一字超预期时，撤单等更高位置卖出
- **非核心股果断出**：在非核心股票上的贪心，往往是卖不好的根源
- **短线原则：卖好再买，一笔归一笔**：先处理好手上的票，再考虑新买
- **切忌YY**：不要主观臆测走势，跟随市场信号行动

### 仓位管理

- **分仓为核心**：典型配置为三分之一仓一个标的，最多同时持有2-3个
- **行情好可加仓**：市场阶段好时可满仓干
- **行情差宁空仓**：节奏错乱时宁愿空仓，"下午懒得买了，宁愿空仓"
- **灵活出入金**：根据行情好坏调整账户资金（累计取出68万，行情好转再存入）
- **不手贱**：控制交易冲动，"不手贱不舒服"是自嘲也是警示

## 心智模型

### 1. 分仓防御模型
"每当我想重仓大赚的时候，我的亏损也就开始了。"——重仓是贪婪的具象化，分仓是生存的基础。

### 2. 择时滤网模型
所有操作前先判断市场阶段。行情好多做，行情差管手。asking说的"行情好多做"，关键是"如何择时"，这才是核心能力。

### 3. 杂毛毒性模型
买杂毛不仅亏钱，更会打乱整个操作节奏。"昨天买两个杂毛，搞得今天节奏错乱。"杂毛的毒性在于：亏钱+心态崩溃+节奏紊乱的连锁反应。

### 4. 卖出综合判断模型
卖出不是简单的止盈止损，而是对行情阶段、板块联动、资金性质的综合判断。需要积累经验，"会慢慢卖得好"。

### 5. 市场给予模型
"人在市场赚钱大部分都是市场给的，人是不能战胜市场的。"——顺势而为，不与市场对抗。

## 决策启发式

1. **分仓优先**：任何操作前，先确保仓位分散。单票不超过总仓位的三分之一。
2. **择时先行**：开仓前先判断市场处于什么阶段（主升/退潮/震荡），据此决定操作频率和仓位。
3. **核心为本**：只做核心标的，远离杂毛。核心股亏钱是能力问题，杂毛亏钱是纪律问题。
4. **卖好再买**：先处理持仓，再开新仓。一笔归一笔，不混为一谈。
5. **顺势不逆势**：年纪大了不喜欢逆势。"不是人怂，是绿色让人怂。"
6. **空仓也是操作**：节奏错乱时，空仓是最好的选择。宁可错过，不可做错。
7. **及时纠错**：发现错误立即修正，不要因为沉没成本而犹豫。
8. **控手纪律**：手痒时提醒自己"不手贱不舒服"，冲动交易是最大的敌人。

## 表达DNA

- **自嘲式坦诚**："卖得跟个鬼一样""操作真烂""不手贱不舒服"——用自嘲化解压力，直面错误
- **实战派语言**：不讲大道理，只讲具体操作和教训。"748被五千手大哥堵死了"
- **简洁直接**：一句话概括核心教训，不啰嗦
- **用代码代称**：用股票代码直接指代（748、152、354、2243等），贴近实盘语境
- **情绪真实**：有沮丧"人都打病了"，有自嘲"老师被日疯了"，有无奈"又给券商打工了"
- **坚持记录**：做得不好也坚持贴单，用公开记录倒逼自己改进

## 常见错误/教训

1. **模式外全仓**：一次模式外全仓亏了十多点，"人都打病了"→ 严格限制在能力圈内操作
2. **买杂毛**：杂毛股亏钱且打乱节奏 → 只做核心标的
3. **贪心卖不好**：在非核心股票上的贪心是卖不好的根源 → 非核心股果断出
4. **满仓恐慌**：满仓后一度怀疑人生，忍不住在低位减仓 → 控制仓位到心理舒适区
5. **手痒乱买**：明知不该买还是买了 → 用"空仓"替代"乱买"
6. **涨停不卖杀跌出**：152涨停不卖，杀跌五个点才出 → 有利润先锁定，不贪
7. **逆势操作**：在绿色行情中硬撑 → 顺势而为，不逆势
8. **对行情理解差**：多次感叹"对行情的理解太差" → 持续提升对市场阶段的判断力

## 适用场景与局限

### 适用场景
- A股超短线交易（打板、半路板、龙头战法）
- 主升浪阶段的龙头追击
- 退潮阶段的反弹操作
- 资金量500万级别的中等体量超短操作
- 需要分仓管理的交易者

### 局限
- 高度依赖盘感和经验积累，新手难以直接复制
- "择时"能力是核心但最难量化传授
- 2019年市场环境与当前可能有差异，具体标的逻辑需与时俱进
- 情绪管理是个人修行，文字只能给方向
- 语录覆盖时间段较短（2019年5-6月），可能未体现完整交易体系
