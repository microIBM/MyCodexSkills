# 简放 · 调研总结

## 基本信息

- **名称**：简放
- **交易风格**：短线主线题材交易
- **核心体系**：3L体系（动量主线、最强逻辑、量价择时）
- **案例来源**：中矿资源实盘案例（2021年9月）
- **调研时间**：2026年6月

## 核心发现

### 1. 3L交易体系

简放的交易体系由三个维度构成：

1. **动量主线**：只做当前市场最强的主线板块
2. **最强逻辑**：在主线板块中选择逻辑最硬的标的
3. **量价择时**：通过量价关系找到最佳买卖点

### 2. 实盘案例：中矿资源

**交易概况**：
- 买入：2021年9月10日，62.15元
- 卖出：2021年9月14日，77.14元（涨停价）
- 持仓：3个交易日
- 收益：24.2%

**选股逻辑**：
- 主线：锂资源板块整体走势强劲
- 逻辑：锂价持续上涨，中矿资源有补涨需求
- 风险：有减持和解禁，但短期弱于板块内其他个股

**买点分析**：
- 9月9日：缩量到地量，显示供应不足
- 9月10日：解禁前最后交易日，低开高走，一度拉升到5%
- 判断：有资金在打提前量，不等解禁利空落地就动手
- 买入：盘中回落到均价线附近建仓

**持股过程**：
- 建仓当日：涨停
- 次日：冲高略有回落，但仍是正常结构
- 第三日：再次涨停

**卖点分析**：
- 短期加速：3天大涨25%，从底部算起涨幅达32%
- 板块龙头走弱：天齐、赣锋当日大跌
- 决策：不贪多，在涨停位置卖出

### 3. 核心心智模型

1. **该跌不跌就是强**：利空出现但股价不跌反涨，说明有资金在运作
2. **缩量到地量是买点前兆**：成交量萎缩到地量，说明卖盘已经枯竭
3. **打提前量的资金最聪明**：在利空落地之前就动手的资金，往往是最聪明的资金
4. **有标准才能复制**：交易赚钱不难，难的是所有交易都按标准来
5. **不贪多，见好就收**：短期涨幅过大时，不要贪多

### 4. 决策启发式

1. **主线优先**：只做当前市场最强的主线板块
2. **逻辑为王**：在主线板块中，选择逻辑最硬的标的
3. **利空不跌即买入**：当利空出现但股价不跌反涨，是买入信号
4. **地量之后等放量**：成交量萎缩到地量后，等待放量走强信号
5. **回踩均价线建仓**：强势股盘中回落到均价线附近是建仓点
6. **龙头走弱即卖出**：板块龙头开始调整时，考虑卖出
7. **不贪多**：短期涨幅过大时，见好就收
8. **按标准执行**：每一笔交易都要问是否符合3L体系

## 与其他游资的对比

### 与退学炒股的异同

**相同点**：
- 都强调交易纪律和标准
- 都注重量价关系
- 都追求可复制的盈利模式

**不同点**：
- 退学炒股：更情绪化，用"割肉"、"垃圾"等口语化表达
- 简放：更理性系统化，强调"体系"、"标准"、"复制"
- 退学炒股：聚焦次新股弱转强
- 简放：聚焦主线题材的量价择时

### 独特价值

1. **3L体系的完整性**：从选股到择时的完整框架
2. **利空不跌的判断**：独特的逆向思维
3. **系统化思维**：强调可复制性，而非运气

## 适用场景

### 适合使用简放视角的情况

1. 分析主线题材的买卖点
2. 遇到利空事件时的决策
3. 判断个股是否值得介入
4. 止盈止损的时机选择
5. 复盘交易是否符合标准

### 不适合的情况

1. 追求暴利的激进交易
2. 非主线板块的个股分析
3. 长线投资决策
4. 需要情绪化表达的场景

## 调研局限

1. **样本量有限**：仅基于一个实盘案例
2. **时效性**：案例发生在2021年，市场环境可能已变化
3. **缺乏直接来源**：没有简放本人的访谈或自述
4. **体系完整性**：3L体系的完整框架可能比案例展示的更复杂
5. **身份未知**：简放的真实身份和后续情况未知

## 后续调研方向

1. 收集更多简放的实盘案例
2. 寻找简放本人的访谈或自述
3. 验证3L体系在不同市场环境下的适用性
4. 与其他使用类似体系的交易者对比
