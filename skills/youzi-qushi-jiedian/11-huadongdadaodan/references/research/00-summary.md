# 华东大导弹 · 调研摘要

## 基本信息

- **网名**：华东大导弹
- **平台**：淘股吧
- **战绩**：10个月10倍（2022年底-2023年上半年，横跨10个月）
- **资金级别**：百万级别
- **比赛成绩**：从最初倒数到冠军，全程参赛，成绩总在前列
- **历史回撤**：多次腰斩

## 核心交易特征

| 维度 | 数据 |
|------|------|
| 月均出手 | 3-5次 |
| 空仓比例 | 60-70% |
| 持仓周期 | 1-3天 |
| 月均收益 | 约10% |
| 选股偏好 | 小盘（几个亿）、高辨识度 |
| 买点偏好 | 打回封板、尾盘竞价、尾盘分批 |
| 卖点规则 | 竞价不及预期即果断离场 |

## 风格定位

- **不是龙空龙**：几乎没参与AI总龙头剑桥，不是围绕龙头做到结束的风格
- **不像退学炒股**：退学很多开盘直接上车、分时低吸，华东大导弹几乎不这样做
- **更像一瞬流光所说**：小资金抓小周期小节点，一次5-10%，一年10倍
- **典型猎豹型**：耐心等待，果断出手

## 关键发现

1. **管住手是最大alpha**：1月4-5次、2月3只、4-5月10次，出手极少
2. **主线大肉 > 杂毛小面**：主线操作大肉居多，杂毛操作小面居多
3. **下午/尾盘买比早上安全**：减少当日回撤
4. **竞价不及预期就走**：执行力极致
5. **辨识度是选股第一标准**：没辨识度不做
6. **庄股可做但有天花板**：3板以上有主线时不去
7. **补涨龙有天花板**：后期补涨高度在4-5板
8. **超短靠银行不可行**：选错标的果断纠错

## 与其他游资的关系

- **一瞬流光（光神）**：华东大导弹的操作完美切合光神所说的"小资金抓小周期小节点"
- **92科比**：引用其"很多炒作都是在模仿"
- **睿神**：引用其"后期补涨高度在4-5板"
- **退学炒股**：风格不同，退学更激进（开盘直接上、分时低吸），华东更稳（打回封、尾盘上）
